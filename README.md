# Customer_Churn_Analysis
End-to-end customer churn analysis project built with Python, MySQL, and an interactive Power BI dashboard.

## 🚀 Project Overview
This project analyzes customer churn patterns to identify key risk factors and help businesses improve customer retention strategies.

## 🛠️ Tech Stack
* *ETL & Data Cleaning:* Python (Pandas, NumPy)
* *Database & Queries:* MySQL (churndb)
* *Data Visualization:* Power BI Desktop

## 📊 Key Features
* Cleaned and preprocessed customer datasets.
* Relational database storage and retrieval using MySQL.
* Interactive Power BI dashboard featuring dynamic cards, bar charts, and visual filters.
